# Échelle de compétence

| Valeur | Libellé              | Description                                                               |
|--------|----------------------|---------------------------------------------------------------------------|
| 0      | Aucune connaissance  |                                                                           |
| 1      | Notions              | Connaissances très limitées ou théoriques. Besoin d'encadrement constant. |
| 2      | Compétence basique   | Peut réaliser des tâches simples avec une assistance ponctuelle.          |
| 3      | Compétence moyenne   | Capable de travailler de manière autonome sur des tâches courantes.       |
| 4      | Compétence confirmée | Capable de gérer des situations complexes et d'aider les autres.          |
| 5      | Expertise            | Référence dans le domaine. Capable d'innover et de définir des standards. |
